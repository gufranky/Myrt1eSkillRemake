# 技能与事件总表

本文档以 `SkillRegistry.CreateDefault` 和 `EventRegistry.CreateDefault` 的实际注册内容为准。截至 `0.51.0-dev`，框架共注册 **88 个技能**与 **32 个事件**。

说明：

- 主动技能使用 `css_useskill` 激活；默认每位玩家最多同时拥有一个主动技能。
- “默认冷却”来自技能描述符；`—` 表示被动技能或不使用通用冷却。
- 稀有度为描述符默认值，服务器配置仍可覆盖技能的稀有度、权重及单服数量限制。
- 事件“权重”是默认抽取权重，服务器配置可以覆盖。
- 组合事件会继续抽取兼容的子事件；冲突解析器可能使实际子事件数少于目标数。
